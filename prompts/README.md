# AI Scientist Workflow Prompts

Complete prompts used in the LossFunk AI scientist pipeline that produced a paper accepted at Agents4Science 2025.

## Files

**Idea Generation**
- **idea_generation/paper_pair_judgement.md** - Evaluate paper pairs for mashing potential.
- **idea_generation/paper_mashing_idea_gen_agentic.md** - Generate novel research ideas.
- **idea_generation/idea_output_format.md** - Structured template for ideas.

**Hypotheses Generation**
- **hypotheses_generation/hypothesis_suite_generation_prompt.md** - Create testable hypotheses.
- **hypotheses_generation/hypothesis_output_format.json** - Structured template for hypothesis output.

**Experiment Planning**
- **experiment_planning/experiment_planning_code.md** - Plan implementation tasks.
- **experiment_planning/visualisation_planning_code.md** - Plan visualization tasks.

**Paper Creation**
- **paper_creation/paper_readiness_check.md** - Check for readiness before paper writing.
- **paper_creation/paper_outline_prompt.md** - Structure final papers.
- **paper_creation/paper_outline_reviewer.md** - Review paper outlines.
